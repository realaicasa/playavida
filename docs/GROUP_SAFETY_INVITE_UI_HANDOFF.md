# Group Safety and Invite-Code Visual Spec

This document outlines the visual prototype for future group moderation and invitation features.

## Future Requirements
- **Email Verification**: Required for all users before joining.
- **Moderation**: Admin approval for all join requests.
- **Invites**: Rate-limited, single-use, expiring codes (non-functional for this prototype).
- **Safety**: Reporting path for groups/members.

## Visual Mock States
- **Join Requests**: Admin dashboard list with approve/reject/block actions (Mock only).
- **Invite Management**: Dashboard section for invite code creation (Non-functional).

## Constraints
- **NO real invite generation.**
- **NO real WhatsApp integration.**
- **NO trust elevation based on invites.**
- **Admin must have manual moderation controls.**
