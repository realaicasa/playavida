## Paid targeted notifications (weekly newsletter concept)
Buyers: event organisers, businesses, group admins, sponsors.
Model: weekly digest with labelled "Sponsored" slots, audience chosen by tag/interest filters, priced per slot or per 1,000 reach; strict caps (e.g. max 1 sponsored item per user per week; value to be tested).
Rules: explicit opt-in per category; one-tap unsubscribe; sponsored items always labelled; advertiser never receives user lists, only aggregate results.
Build: tag taxonomy -> audience filter UI (preview reach count) -> campaign checkout (Stripe) -> review/approval -> scheduled send -> results report.

## Social auto-posting
Trigger: new group/business/event approved (not just posted, to avoid spam/scams).
Flow: Teable record -> webhook/automation -> template + AI caption EN/ES -> queue -> auto or one-click approve -> Facebook Page, Instagram (professional account), later X/LinkedIn.
Feasibility: yes via Meta Graph API or an automation tool (Make/n8n/Zapier). Platform rules, app review and costs change: verify before committing.

## Licensing/franchise
Package: white-label instance, settings-driven config, operations playbook, moderation guide, sales scripts, onboarding checklist, brand/licence terms. Needs legal review in the licensee's jurisdiction.
